# NCE Portfolio

Personal portfolio of **Nicole Camacho Edades** (BSIT 1N-B), built from the Lab Activity 8.2 high-fidelity prototype.

Pages: Home · About · Skills · Projects · Achievements · Contact (one `index.html`, switched with `#about`, `#projects` and so on).

## Run it
Open `index.html` in a browser. No build step.

## Publish with GitHub Pages
Settings → Pages → Source: *Deploy from a branch* → `main` / root.

## Editing
- Text lives directly in `index.html`.
- Projects, certificates, skills and social links are lists near the top of the `<script>` block (`PROJ`, `CERT`, `TS`, `SS`, `SO`).
- Colors are CSS variables at the top of `<style>` (light and dark themes).

## Design prototype
`prototype/` holds the Lab Activity 8.2 high-fidelity prototype: the full PDF (style guide, component sheet, desktop and mobile mockups, change log, process screenshots) and each page as a PNG.
